微信读书网关版本对齐

核对官方完整 Skill 后，将 Talebook 的请求版本对齐到 1.0.5，解除旧版本触发的升级要求。

状态：ACTIVE 创建日期：2026-11-01 所属模块：webserver 需求来源：开发者反馈微信读书插件升级提示

原始诉求

开发者反馈：talebook 的微信阅读插件显示“微信读书 Skill 有新版本，请立即从 upgrade_url 下载最新版 SKILL.md 及子文件替换本地版本，然后重新执行用户请求”。

本会话没有包含 upgrade_url 的具体值或待重试操作。当前环境也没有已安装的微信读书 Skill 或开发者的 Talebook 实例连接。

目标与边界

本次按插件兼容性维护处理：下载官方 SKILL.md 和全部八份子文档，核对现有接口后更新后端请求版本及回归断言。账号凭据、接口参数与导入模型保持现有协议。

Talebook 通过 Python Provider 直接调用网关，不加载本地 SKILL.md，因此仅替换 Markdown 无法改变插件上报的版本。运行时不自动下载或执行远程文件，也不借用其他读者的凭据。

现状与证据

WereadProvider._gateway 固定上报 1.0.4，收到 upgrade_info 时抛出 UpstreamError。腾讯官方 skills/SKILL.md 当前声明 1.0.5。

协议来源：腾讯官方完整 Skill，固定提交 d98e66ee60a8c7bcd35da549d0643c4470439643。

与 releasev1.0.4 对比，1.0.5 更新版本字段，并补充 readerLink 和 deepLink 的解释；本插件已有读操作的接口名、鉴权、参数平铺规则没有变化。

方案与决策

  1. 将 WEREAD_SKILL_VERSION 更新为经过协议核对的 1.0.5，并在常量旁注明官方来源。
  2. 同步现有全部读操作的网关请求回归测试，继续检查参数平铺及凭据只放请求头。
  3. 保留升级阻断行为；未来上游再升级时需要重新核对完整文档，不能忽略升级通知或伪造版本号。

影响范围与风险

影响 webserver/plugins/combo/weread/provider.py 、tests/test_weread_plugin.py 及 spec/插件/微信读书.md 的版本维护说明。

无界面影响：本次只更新后端网关协议版本，不修改页面、布局、交互、前端回包结构或文案。属于版本兼容性维护，豁免大型功能的 interface-review。风险为上游后续升级仍需维护；真实账号验证依赖开发者部署及自己的连接。
